**Paperlings – hudební aktualizace (kandidát 1.0.0-rc2)**

- Čtyři dodané skladby se střídají po jednotlivých misích, opakují se
  s prolínáním a mají samostatnou uloženou hlasitost.
- Restart, pauza, rychlost hry a přetočení nechávají hudbu pokračovat.
- Herní pravidla, mise a formát uloženého postupu zůstávají stejné.

Windows balíček obsahuje hudbu. Spuštění přímo na Windows zatím nebylo
ověřeno; před zveřejněním je třeba rozlišit export a nativní test.
Sestavení nemá podpis Microsoftu, systém může při prvním spuštění varovat.

**Android rc2 obsahuje stejnou hudbu.** Na výslovné přání autora má
nový podpis a vlastní identitu (`cool.jenda.paperlings`). Nainstaluje se
jako nová aplikace vedle staré testovací hry, začíná od první mise
a nepřebírá uložený postup. Během hraní pak nový postup normálně ukládá.
Zálohování dat do systému je vypnuté. Starou aplikaci není nutné odinstalovat.

Kontroly hudby a její původ: [HUDBA.md](../HUDBA.md).
Zveřejnění této poznámky samo o sobě neznamená dostupné GitHub Release
nebo dokončené nahrání na web.
