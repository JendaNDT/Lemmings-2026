# Lemmings 2026 — Android 0.7.0

[**Stáhnout APK (61 MiB)**](https://github.com/JendaNDT/Lemmings-2026/raw/refs/heads/downloads/android-0.7.0/android/Lemmings-2026-Android-0.7.0.apk)

Nově **kampaň po kapitolách** s hvězdami 1–3, **úvodní karta** každé mise
(cíl, dovednosti s popisem, co je nového, obtížnost), **nápověda** v pauze,
nové výukové mise kapitoly I a **Hřiště** se všemi dovednostmi.

![Úvodní karta mise z herních souborů tohoto APK (Linux, dotykový profil, ne telefon)](https://raw.githubusercontent.com/JendaNDT/Lemmings-2026/00ef69ed220c5144206be5567730620c3a79bb7f/docs/images/android-0.7.0.jpg)

**Verzi 0.5.0 a 0.6.0 aktualizuje přímo** (stejný testovací podpis),
uložený postup zůstane. Verzi 0.4.0 a starší nejdřív odinstaluj.

1. Stáhni APK přímo na telefon nebo tablet a otevři jej.
2. Pokud Android požádá, povol instalaci pro použitý prohlížeč/správce souborů.
3. Hraj na šířku. V menu zvol *Začít hrát* nebo *Mise*. Na úvodní kartě
   klepni *Hrát*, pak vyber dovednost a klepni na postavu. Tlačítko Zpět
   otevře pauzu s nápovědou.
4. Všechny mise hned otevře **Nastavení → Hra → Všechny mise odemčené**.

Android 7.0+, ARM32/ARM64, OpenGL ES 3.0. Bez Android oprávnění.
Verze 0.7.0 (versionCode 8), balíček `org.lemmings2026.demo`.
Nativní běh a výkon na telefonu zatím neověřené; herní soubory z APK
prošly v Linuxu celým průchodem menu, mise a ukládání. Před exportem prošlo
380 automatických kontrol.
