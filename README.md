# Lemmings 2026 — Android 0.6.0

[**Stáhnout APK (66 MiB)**](https://github.com/JendaNDT/Lemmings-2026/raw/refs/heads/downloads/android-0.6.0/android/Lemmings-2026-Android-0.6.0.apk)

Nově **hlavní menu**, **výběr misí** se zámky a rekordy, **nastavení**
(hlasitosti, velikost rozhraní, kvalita efektů, ovládání), pauzovací menu
a **ukládání postupu** – rozehraná mise se uloží a „Pokračovat“ ji obnoví.
K tomu papírová origami grafika, šest misí a zvuky (hudba přijde později).

![Výběr misí z herních souborů tohoto APK (Linux, dotykový profil, ne telefon)](https://raw.githubusercontent.com/JendaNDT/Lemmings-2026/6b2b5d6159763b2ccaef57f222a06afceaeb7f19/docs/images/android-0.6.0.jpg)

**Verzi 0.5.0 aktualizuje přímo** (stejný testovací podpis).
Verzi 0.4.0 a starší nejdřív odinstaluj.

1. Stáhni APK přímo na telefon nebo tablet a otevři jej.
2. Pokud Android požádá, povol instalaci pro použitý prohlížeč/správce souborů.
3. Hraj na šířku. V menu zvol *Začít hrát*. Ve hře vyber dovednost a klepni
   na postavu; jedním prstem posouvej, dvěma přibližuj. Tlačítko Zpět
   otevře pauzovací menu.
4. Mise se odemykají postupně. Všechny hned otevře
   **Nastavení → Hra → Všechny mise odemčené**. Počítadlo FPS je
   v Nastavení → Zobrazení.

Android 7.0+, ARM32/ARM64, OpenGL ES 3.0. Bez Android oprávnění.
Verze 0.6.0 (versionCode 7), balíček `org.lemmings2026.demo`.
Nativní běh a výkon na telefonu zatím neověřené; herní soubory z APK
prošly v Linuxu celým průchodem menu a ukládání. Před exportem prošlo
395 automatických kontrol.
