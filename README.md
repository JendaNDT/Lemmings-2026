# Lemmings 2026 — Android 0.5.0

[**Stáhnout APK (66 MiB)**](https://github.com/JendaNDT/Lemmings-2026/raw/refs/heads/downloads/android-0.5.0/android/Lemmings-2026-Android-0.5.0.apk)

Nová papírová **origami grafika** s paralaxní krajinou, šest misí včetně
nové „6 · Voda, láva a past“ a **zvuky** (hudba přijde později).

![Hra spuštěná z herních souborů tohoto APK (Linux, ne telefon)](https://raw.githubusercontent.com/JendaNDT/Lemmings-2026/64fb2826de9f3415638af37a937cd34eafcd6532/docs/images/android-0.5.0.jpg)

**Nejdřív odinstaluj verzi 0.4.0.** Toto APK má jiný testovací podpis,
takže by se přes starou verzi nenainstalovalo („Aplikace nebyla
nainstalována“). Hra zatím neukládá postup, nic se neztratí.

1. Stáhni APK přímo na telefon nebo tablet a otevři jej.
2. Pokud Android požádá, povol instalaci pro použitý prohlížeč/správce souborů.
3. Hraj na šířku. Vyber dovednost, pak klepni na postavu. Jedním prstem
   posouvej, dvěma přibližuj. Mise se vybírají vlevo dole, reproduktor
   vpravo dole ztlumí zvuk.

Android 7.0+, ARM32/ARM64, OpenGL ES 3.0. Bez Android oprávnění.
Verze 0.5.0 (versionCode 6), balíček `org.lemmings2026.demo`.
Nativní běh a výkon na telefonu zatím neověřené; herní soubory z APK
běžely v Linuxu. Před exportem prošlo 327 automatických kontrol.
