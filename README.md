# Lemmings 2026 — Android 0.4.0

[**Stáhnout APK (60 MiB)**](https://github.com/JendaNDT/Lemmings-2026/raw/refs/heads/downloads/android-0.4.0/android/Lemmings-2026-Android-0.4.0.apk)

Nová modelínová grafika: zaoblené hrany terénu i kopání, výraznější postavička,
modelované pozadí, světlo a čitelná lišta. Osm dovedností a pět volitelných scén.

![Skutečná hra, desktopový renderer](https://raw.githubusercontent.com/JendaNDT/Lemmings-2026/b5569c1578953f5b363dcdef4e4ca2cd04b82db2/docs/images/art-pass-0.4.0.png)

1. Stáhni APK přímo na telefon nebo tablet a otevři jej.
2. Pokud Android požádá, povol instalaci pro použitý prohlížeč/správce souborů.
3. Hraj na šířku. Vyber dovednost, pak klepni na postavu. Jedním prstem
   posouvej, dvěma přibližuj. Mise se vybírají vlevo dole.

Android 7.0+, ARM32/ARM64, OpenGL ES 3.0. Bez Android oprávnění.
Testovací APK má stejný podpis jako 0.3.0, může aktualizovat předchozí instalaci.
Nativní výkon telefonu/tabletu zatím neověřený; grafické a dotykové průchody
běžely v Linuxu. Prošlo 186 automatických kontrol, první mise 20/20, nové mise
6/6, 6/6 a 3/4. Finální grafika celé kampaně a zvuk ještě nejsou dokončené.
