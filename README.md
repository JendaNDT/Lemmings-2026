# Paperlings 1.0.0-rc2 – s hudbou

Obě verze obsahují všechny čtyři hudební skladby.

- [Android APK](android/Paperlings-1.0.0-rc2-Android.apk): Android 7+, nová samostatná instalace bez starého postupu. Starou hru neodinstalovávej, není to potřeba.
- [Windows ZIP](windows/Paperlings-1.0.0-rc2-Windows.zip): Windows 10/11 x64. Rozbal a spusť Paperlings.exe.

Android má novou identitu cool.jenda.paperlings a nový podpis. Další aktualizace
musí použít tento podpis; klíč zde není. Nový postup se normálně ukládá.
Windows sestavení není digitálně podepsané. Nativní testy na obou zařízeních
ještě neproběhly; exporty, obsah hudby a kontrolní součty prošly kontrolou v cloudu.

Zdrojový kód: větev ccr-ee49bb72-jyyh2r, commit 59fc41a0a1ff14ca96fdde761591e6fee2009257.
