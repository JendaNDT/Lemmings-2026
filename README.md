# Paperlings 1.0.0-rc3 – Android

Aktualizace vykreslování pro telefony a tablety. Hra má 24 misí a všechny čtyři hudební skladby.

[**Stáhnout APK**](https://raw.githubusercontent.com/JendaNDT/Lemmings-2026/refs/heads/downloads/android-1.0.0-rc3/android/Paperlings-1.0.0-rc3-Android.apk)

Instalovat přímo přes rc2, neodinstalovávat: identita i podpis jsou stejné a postup zůstane.
Android 7.0+, ARM32/ARM64, versionCode 1000003, balíček cool.jenda.paperlings.
Starší testovací aplikaci org.lemmings2026.demo tento balíček neaktualizuje.

Android nyní vykresluje do návrhového HD viewportu; tráva používá společnou geometrii.
Na displejích s vysokým rozlišením je obraz mírně měkčí. Nativní FPS na uživatelově tabletu
čeká na ověření; cloudové grafické kontroly a herní testy prošly.

[Podrobnosti a ověření](https://github.com/JendaNDT/Lemmings-2026/blob/ccr-ee49bb72-jyyh2r/docs/VYKON_ANDROID.md)

Windows s hudbou zůstává ve [vydání rc2](https://github.com/JendaNDT/Lemmings-2026/tree/downloads/android-1.0.0-rc2).
V této větvi jsou pouze distribuční soubory; zdroje jsou ve větvi ccr-ee49bb72-jyyh2r.
