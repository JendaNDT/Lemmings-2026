# Paperlings 1.0.0-rc1 – Android

[**Stáhnout APK (72 MiB)**](https://github.com/JendaNDT/Lemmings-2026/raw/refs/heads/downloads/android-1.0.0-rc1/android/Paperlings-1.0.0-rc1-Android.apk)

Kandidát na vydání 1.0 pod novým jménem **Paperlings** – stejná hra jako
testovací verze, s novou ikonou, obrazovkou **O hře** (titulky, návod,
licence, Nahlásit chybu) a sestavením i pro Windows a macOS na stránce
[vydání](https://github.com/JendaNDT/Lemmings-2026/releases/tag/v1.0.0-rc1).

![Ikona, menu a O hře z herních souborů vydání (Linux, ne telefon)](https://raw.githubusercontent.com/JendaNDT/Lemmings-2026/596a1d36049690b33a9ab03332852b96c0d46ece/docs/images/vydani-1.0.0-rc1.jpg)

**Aktualizuje testovací verze 0.5.0–0.15.0** (stejný balíček i podpis),
uložený postup, hvězdy i nastavení zůstanou. Verzi 0.4.0 a starší nejdřív
odinstaluj.

1. Stáhni APK přímo na telefon nebo tablet a otevři jej.
2. Pokud Android požádá, povol instalaci pro použitý prohlížeč/správce souborů.
3. Hraj na šířku. Návod je ve hře v **O hře → Jak hrát**.

Android 7.0+, ARM32/ARM64, OpenGL ES 3.0. Bez Android oprávnění.
Verze 1.0.0-rc1 (versionCode 1000001), balíček `org.lemmings2026.demo`.
Nativní běh na telefonu zatím neověřený; herní soubory z APK prošly
v Linuxu průchodem menu (24 misí) a obrazovkou O hře. Před exportem prošlo
455 automatických kontrol.
